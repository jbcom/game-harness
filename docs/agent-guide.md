Repository instructions for agents live in [AGENTS.md](https://github.com/jbcom/game-harness/blob/main/AGENTS.md). They cover the public API, silent-browser contract, package boundaries, validation, Sourcey documentation architecture, Conventional Commits, and protected merge workflow.

The repository-root `llms.txt` is a concise agent index. Sourcey generates
separate `llms.txt` and `llms-full.txt` files in the documentation build; those
describe this documentation site and are not manually maintained copies.
